# Personal Trading Engine — Downloads

This repository hosts installer downloads for Personal Trading Engine, a Windows desktop app for personal crypto trading strategy testing (PAPER/SHADOW simulation, with a separate LIVE build for real order execution). Source code is maintained privately.

이 저장소는 Personal Trading Engine의 설치 파일 다운로드만 제공합니다. 소스 코드는 비공개로 관리됩니다.

- See the [Releases](../../releases) page for the latest test build.
- Every release includes SHA-256 checksums and a short test guide.
- 최신 시험판(RC)은 [Releases](../../releases) 페이지에서 확인하세요.
